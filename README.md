# XAM.AI - AI-Powered Study Platform

The ultimate AI-powered study platform featuring neural synthesis, group nexus rooms, and accelerated cognitive flux.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
